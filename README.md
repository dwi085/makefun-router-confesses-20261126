A one-line excuse from a home Wi-Fi router for dropping the connection at a movie's climax. The router is not sorry about the buffering — it is jealous: the film got a climax and all it ever gets is a blinking light, so it dropped the connection because it wanted one dramatic moment too.

## Run it

```sh
node main.ts
```

This writes a single line (125 characters) to `/output/entry.txt`.
